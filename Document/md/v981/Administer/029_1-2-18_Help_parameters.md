1.2.19.1. ir_disable

Parameter

ir_disable

Description

This parameter allows you to disable the IR keys on your existing Service Manager system, so that
the upgrade process runs faster.

            Note

           After the application upgrade succeeds, you can enable the IR keys again by removing
           the ir_disable:1 entry from the sm.ini file.

The following table describes different system behaviors based on the value of this parameter.

Value                                   Description
1 or empty                              The IR keys are disabled.
0                                       The IR keys aren't disabled.

                                                 Note

                                                 By default, this parameter is not
                                                 specified and value "0" is used.

Valid if set from

Server's operating system command prompt
Initialization file (sm.ini)

Requires restart of the Service Manager server?

Yes

Default value

0

Possible values

1 or empty (Disable the IR keys)
0 (Enable the IR keys)

Example usage


Command line: sm ir_disable:1

Initialization file: ir_disable:1

1.2.19.3. ir_pending_secs

Parameter

ir_pending_secs

Description

This parameter is only for the Oracle database. Use this parameter to control the maximum pending
period (in seconds) before an IR index gets synchronized after the base table is updated. The
default and minimum value is 3600 seconds. The bigger the value, the later IR search can search
out the new text terms. However, a bigger value also means a smaller impact on the memory and
other resources of the DB server.

            Note

           After changing this parameter, make sure that you run sm -upgradeir for the change
           to take effect as it only works after IR re-generates the existing indexes, or for newly
           created IR indexes.

Valid if set from

Server's operating system command prompt
Initialization file (sm.ini)

Requires restart of the Service Manager server?

Yes

Default value

3600

Possible values

Number of seconds greater than or equal to 3600

Example usage

Command line: ir_pending_secs:7200
Initialization file: ir_pending_secs:7200

1.2.19.4. ir_stoplist

Parameter

ir_stoplist

Description

This parameter specifies your own stoplist if you don't want to use the default database stoplist.

            Important

           :
           Start from Service Manager p1 and 9.70 version, this parameter is only available for
           PostgresSQL databases. As for Oracle and MS SQL Server, you need to follow the
           instrustions in the Manage IR Stop Words page to migrate your existing stoplist (if you
           have specified in previous versions) and maintain your own stoplist using the IR Stop
           List Management tool.

To create or update the PostgresSQL database stoplist, see the following documentation:
https://www.postgresql.org/docs/11/textsearch-dictionaries.html#TEXTSEARCH-STOPWORDS
After you create or update the stoplist, make sure that you run the sm -upgradeir command to
regenerate IR indexes.

Valid if set from

Server's operating system command prompt
Initialization file (sm.ini)

Requires restart of the Service Manager server?

Yes

Default value

None

Possible values

The file name of your database stoplist.

Example usage

Command line: sm - ir_stoplist:mysmstoplist
Initialization file: sm - ir_stoplist:mysmstoplist
